# JavaScript Complete Course - Study Project

This repository is a hands-on study project for learning JavaScript from the fundamentals to more advanced topics. It includes exercises, mini-applications, DOM manipulation practice, object-oriented programming, modern JavaScript, AJAX, and front-end development projects.

The goal of this project is to strengthen practical understanding through real examples and small apps that reflect common web development workflows.

## Project Summary

This course covers:

- Core JavaScript fundamentals
- Variables, operators, and control flow
- Functions and scope
- Arrays, objects, and data structures
- DOM manipulation
- Events and interactivity
- Object-oriented programming
- Modern JavaScript (ES6+)
- Asynchronous JavaScript and AJAX
- API consumption
- Small front-end applications and UI projects

The repository is organized into modules, each focused on a specific topic or application, making it easier to study progressively and revisit concepts as needed.

## How to Use This Project

1. Clone the repository.
2. Open the project locally.
3. Explore the folders in order.
4. Read the code and test the examples in the browser.
5. Practice by modifying the examples and building your own variations.

For simple static examples, you can open the HTML file directly in the browser. For more advanced sections, using a local development server is recommended.
